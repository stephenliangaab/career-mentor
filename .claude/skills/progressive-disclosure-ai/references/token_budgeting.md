## Token Budgeting（低成本优先）

### 目标
- 降低平均token：让“每次推荐”尽量只走 Stage1 + Stage2（Stage3按需）
- 降低失败率：输出更短、更结构化、更稳定

## 推荐预算（可按模型再微调）

### Stage1_Rank（L0候选包）
- **目标**：筛选Top3 / TopN
- **建议**：\n  - 候选岗位数量：8-12\n  - 每个岗位L0描述：<= 50-80字（合并字段后）\n  - 输出：仅jobId + 短理由标签\n

### Stage2_Finalize（TopN L1扩展）
- **目标**：生成结果页Recommendation JSON
- **建议**：\n  - 只提供TopN（3-5）岗位的L1\n  - `summary` <=80字\n  - 每岗理由<=3条，每条<=20字\n

### Stage3_ExpandDetail（按需）
- **目标**：生成岗位详情页路径地图\n
- **建议**：\n  - 只对用户点击的岗位调用\n  - steps 3-5步\n  - 每步只给“动作产出+关键技能”，避免长叙述\n
