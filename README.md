## 职径导航（前端为主 + Serverless Functions）

### 这是什么
- **定位**：面向中国大学生与职场新人（1-3年），提供"行业岗位职业规划导航"的轻量Web工具。
- **目标**：在 5 分钟内让用户得到"更适合的方向/岗位 + 可执行的路径地图（里程碑/技能/薪资区间）"，用于冷启动验证。

### 你应该从哪里开始看
- **产品需求（PRD）**：`PRD.md`（页面、流程、字段、AI与限流、埋点、验收标准）
- **岗位库v1（内容清单与模板）**：`岗位库v1.md`（互联网31岗的建议清单 + 填写模板）
- **商业概要（BRD）**：`BRD.md`
- **技术方案草案（参考）**：`技术执行方案.md`

### MVP范围（摘要）
- **内容范围**：互联网行业 31 个岗位（技术/产品/运营/数据/设计/市场/销售）
- **核心闭环**：画像填写 → 推荐 Top3 岗位 → 岗位详情（路径/技能/薪资等）
- **关键画像字段**：身份、学历层级、MBTI（可选简测）、专业、实习/当前岗位、方向偏好、兴趣标签
- **推荐方式**：AI API（低成本优先），通过 Vercel Serverless Functions 转发并限流，避免前端直连暴露Key

### 页面说明

#### P0 - 首页/引导页
- **位置**：`index.html` 中的 `#page-home`
- **功能**：展示产品价值主张，引导用户开始规划
- **关键元素**：Logo、标题、副标题、特色标签、CTA按钮、隐私提示

#### P1 - 画像收集页
- **位置**：`index.html` 中的 `#page-profile`
- **功能**：收集用户背景和偏好信息
- **表单字段**：
  - 身份（必填）：应届毕业生 / 在职1-3年
  - 学历层级（必填）：985 / 211 / 双一流 / 其他
  - 专业（必填）：文本输入
  - 当前经历（选填）：文本输入
  - 方向偏好（必填）：技术/产品/运营/数据/设计/市场/销售
  - 兴趣标签（必填，最多5个）：多选标签
  - MBTI（可选）：16型下拉选择

#### P2 - 推荐结果页
- **位置**：`index.html` 中的 `#page-result`
- **功能**：展示Top3推荐岗位及理由
- **内容**：推荐摘要、3个岗位卡片（排名/名称/理由/风险提示）
- **交互**：点击卡片进入岗位详情、返回修改画像、重新生成

#### P3 - 岗位详情页
- **位置**：`index.html` 中的 `#page-detail`
- **功能**：展示完整的职业发展路径和关键信息
- **内容区块**：
  - 岗位头部（名称、一句话定位）
  - 学历层级建议（针对用户学历）
  - 职业发展路径（3-5个里程碑）
  - 核心技能要求
  - **公司机会分析**（新增）：根据用户学历判断进入大厂/中厂/小厂的机会，展示北上广深四个城市的互联网大厂和中厂列表
  - **分级薪资参考**（新增）：将薪资按照大厂/中厂/小厂三个等级进行划分展示（入门/1-3年/3-5年）
  - 入门岗位示例
  - 风险提示

### 设计系统
- **风格**：Flat Design（扁平化设计）
- **主色**：#6366F1 （Indigo）
- **辅色**：#818CF8 （淡紫）
- **CTA色**：#10B981 （祖母绿）
- **背景色**：#F5F3FF （淡紫背景）
- **字体**：Plus Jakarta Sans （友好、现代、专业）
- **特点**：简洁、无阴影、快速加载、清晰过渡

### 数据说明
- **岗位数据**：`src/data/jobs-data.js` 包含31个互联网岗位的完整信息
  - 技术类（6个）：前端、后端、移动端、测试、DevOps、数据开发
  - 产品类（5个）：产品经理、增长产品、商业化产品、PMO项目管理、产品运营
  - 运营类（11个）：用户运营、内容运营、活动运营、行业运营、UG客户增长、内容新媒体运营、策略运营等
  - 数据类（3个）：数据分析师、数据产品经理、战略商分
  - 设计类（2个）：UI设计师、交互/UX设计师
  - 市场类（3个）：市场营销/品牌、广告投放/增长营销、营销策划
  - 销售类（3个）：ToB销售、售前/解决方案顾问、大客户销售
- **公司数据**：`src/data/companies-data.js` 包含北上广深四个城市的互联网大厂和中厂列表
- **数据结构**：遵循PRD定义的Job模型
- **包含字段**：
  - 基础信息（名称、分类、定位）
  - 职业路径（3-5个里程碑，每个包含时长/产出/技能）
  - 薪资区间（入门/初级/中级，作为基准薪资）
  - 学历建议（针对4个学历档次）
  - 入门岗位、风险提示等
- **公司机会判断**：根据用户学历（985/211/双一流/其他）判断进入大厂/中厂/小厂的机会等级
- **分级薪资计算**：将基准薪资按照大厂（×1.3）、中厂（×1.0）、小厂（×0.8）进行分级展示

- **环境变量**：在Vercel项目设置中配置 `OPENAI_API_KEY`

- ✅ API Key仅存在Vercel环境变量，前端无法访问

- ✅ 成本控制：超额后自动降级到规则推荐

## 后端API说明

### API端点
- **推荐接口**: `POST /api/recommend`
- **统计接口**: `GET /api/recommend/stats`

### 核心功能
1. **AI推荐生成**: 使用OpenAI GPT-3.5-turbo生成个性化推荐
2. **智能缓存**: 相同画像缓存7天，提高响应速度
3. **多层限流**: 月1000次/日50次/IP 5次，防止滥用
4. **自动降级**: API失败时自动切换到规则推荐
5. **成本控制**: 通过缓存和限流控制月度成本在$2以内

### 快速开始

#### 本地开发
```bash
# 安装依赖
npm install

# 启动本地API服务器
npx vercel dev

# 访问: http://localhost:3000
```

#### 部署到Vercel
```bash
# 安装Vercel CLI
npm install -g vercel

# 登录
vercel login

# 部署
vercel --prod

# 详细步骤见 DEPLOY.md
```

#### 配置环境变量
```bash
# 添加OpenAI API Key
vercel env add OPENAI_API_KEY

# 在Vercel Dashboard中启用KV存储
```
